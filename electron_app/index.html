Compilação do Sistema Web Necessária

O sistema web ainda não foi compilado na sua máquina. Para gerar os ficheiros e abrir com o visual idêntico ao sistema web, execute no seu terminal da pasta raiz:

npm run build

Dica: Ou inicie o servidor com npm run dev para ligação direta em tempo real.
